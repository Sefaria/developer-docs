The Sefaria Linker recognizes references on a web page and links them to the corresponding texts on Sefaria. It also offers the option to display a pop-up containing the reference text.

The Linker can be run either as a bookmarklet from a browser or embedded into page code.  The embedded code is meant for website admins to offer the Sefaria Linker to their users while the bookmarklet is meant for individuals who want to see the Sefaria Linker on any site they visit.

If run as a bookmarklet, a user can find references on any webpage he or she visits by clicking the bookmarklet.  If embedded into page code, it will find references every time any user loads the page.  (You can get browser bookmarklets [here](http://www.sefaria.org/linker))
