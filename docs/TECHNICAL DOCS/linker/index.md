The Sefaria Linker recognizes references on a web page and links them to the corresponding texts on Sefaria. It also offers the option to display a pop-up containing the reference text.

The Linker can be run either as a bookmarklet from a browser or embedded into page code.  The embedded code is intended for website admins, allowing them to cite references for their users, while the bookmarklet is meant for individuals who want to see the links to source texts in the Sefaria Library on any site they visit.

If run as a bookmarklet, a user will find references on any webpage by clicking the bookmarklet. If embedded into the page code, it will find references every time any user loads the page in question. 

To get browser bookmarklets, [see here](http://www.sefaria.org/linker)).
